# Coffee Map Component

Интерактивная карта мира для отслеживания кофейных зерен с фильтрацией и поиском.

## Функциональность

### Основные возможности

- **Интерактивная карта мира** с использованием react-simple-maps
- **Маркеры кофейных лотов** с координатами происхождения
- **Клик по континентам** для автоматического выбора в фильтрах
- **Поиск по странам** и регионам
- **Множественные фильтры** по различным характеристикам кофе

### Фильтры

- **Тип зерна** (обжарка): фильтр, эспрессо
- **Способ обработки**: натуральный, мытый
- **Вкус кофе**: цветочный, цитрусовый, ягодный, фруктовый, ореховый, шоколадный и др.
- **Континент**: автоматически заполняется из данных
- **Поиск поставщика**: текстовый поиск

### Интерактивность

- **Hover эффекты** на странах и маркерах
- **Клик по стране** добавляет континент в фильтры
- **Tooltip** с информацией о лоте при наведении на маркер
- **Визуальное выделение** стран с кофейными лотами

## Технические детали

### Зависимости

- `react-simple-maps` - для отображения карты
- `@types/react-simple-maps` - TypeScript типы

### API интеграция

- Использует endpoint `/api/map/all` для получения данных
- Автоматически извлекает доступные фильтры из данных
- Поддерживает real-time фильтрацию без дополнительных запросов

### Структура данных

Компонент ожидает данные в формате:

```typescript
interface CoffeeMarker {
    markerID: number;
    longitude: number;
    latitude: number;
    CoffeeLot: {
        name: string;
        Region: {
            name: string;
            Country: {
                name: string;
                Continent: {
                    name: string;
                };
            };
        };
        Roasting: { name: string };
        ProcessingMethod: { name: string };
        TasteTags: Array<{ name: string }>;
    };
}
```

## Стилизация

Использует CSS модули с кофейной цветовой схемой:

- **Основной цвет**: #8b4513 (коричневый кофе)
- **Фон**: #f5f1eb (кремовый)
- **Акценты**: различные оттенки коричневого

Адаптивный дизайн с поддержкой мобильных устройств.
